# Neo Ledger 服务条款（上线前法务审阅草案）

> 这是产品边界草案，不是法律意见。

1. Neo Ledger 是个人财务记录工具，不提供投资、信贷、税务或支付建议；预测和 AI 输出仅供参考。
2. 用户对导入文件、同步密钥、第三方 WebDAV 和自托管环境的安全负责；平台不会要求用户发送明文备份。
3. 托管服务公开状态、版本支持期、RPO/RTO、维护窗口和事故通知方式；不可用或计费故障不得阻止用户导出数据。
4. 试用、订阅、退款、取消、欠费宽限、只读期、发票和数据删除期限按地区定价页执行，价格变更提前通知。
5. 禁止上传他人未授权的财务信息、绕过访问控制、扫描内网或将 WebDAV 当作代理。
6. 用户可通过 [支持地址] 请求导出、更正、删除、漏洞响应和争议处理。
