# Neo Ledger 移动端预发布说明（草稿）

状态：未发布；版本号、签名包、部署窗口和回滚责任人尚未确认。本文用于正式发布前核对，不代表当前工作树已经分发。

## 主要更新

- 原生记账、账单查询与详情、账户/转账、预算结转、订阅暂停、周期任务、资产预测和待办账期体验继续补强。
- Android 与 iOS 的截图识别先在设备本地 OCR、脱敏后再按次征得用户同意；原图不发送给识别 API，也不会绕过用户确认自动写入账本。
- 移动端支持离线记账队列、失败恢复、写入幂等保护和共享账本修订号刷新；业务数据仍由 Web、Windows、macOS、Android、iOS 共用的服务端处理。
- 原生资料与设置增加头像裁剪压缩、MFA 管理、备份恢复入口、用户主动复制的脱敏 API 诊断，以及记账页硬件键盘快捷输入。

## 数据迁移与兼容

当前工作树包含数据库 schema 36–41 的顺序迁移：账户停用/排序；转账更新与删除时的余额冲正；预算结转开关；订阅暂停；周期记账任务；账单识别来源、脱敏文本、字段完整度与修正记录。

迁移使用默认值或新增表/字段，不应删除既有账单。正式部署前仍必须在备份副本和目标环境验证迁移幂等、旧客户端读取、备份恢复以及回滚路径；尚未执行生产迁移。

## 权限与隐私

- Android 自动记账依赖用户主动在系统设置中授权通知读取、无障碍及厂商后台运行能力；应用不应把系统授权描述成默认已开启。iOS 不提供后台读取其他应用通知/界面的能力，系统分享扩展也尚未完成。
- 截图识别由用户逐次确认；原图和原始 OCR 只在本机临时处理。脱敏 API 诊断最多在内存中保留 20 条摘要，必须由用户主动复制；不自动上传崩溃栈或账单内容。
- 当前 Android Manifest 声明网络、网络状态、开机启动及安装更新相关权限，并注册需系统授权的通知/无障碍服务。正式发布时须和上一正式包逐项 diff 后确认是否有新增权限及对应说明。

## 已知限制

- 当前只验证 Android Debug APK；iOS 的 Xcode/CocoaPods 构建、签名与 TestFlight 尚未验收。
- 账单图片附件对象存储和跨端展示、iOS Share Extension、真机无障碍/性能/弱网矩阵、正式签名升级和回滚演练仍未完成。
- 已提供当前账本标签词库管理，以及明确标注的“清除本机缓存”入口；本机清理不会删除云端账单、登录信息、应用设置或待同步流水。远端账本/整个账号清空仍不提供，避免误删财务数据。
- 当前工作树未发布，不应作为正式版覆盖安装包。

## 回滚注意事项

正式发布前需由发布负责人准备并验证目标数据库备份、上一稳定客户端安装包及服务端回退方案。迁移均按向前兼容思路设计；不得仅回退客户端就假定数据库可安全降级，也不得以删除新增列/表作为默认回滚操作。未完成备份恢复和升级/回退演练前不得发布。
