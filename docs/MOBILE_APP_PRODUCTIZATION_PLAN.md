# Neo Ledger 移动端精品化完善计划

更新时间：2026-09-25
执行起点：Native `1.4.0+21`  
适用平台：Android、iPhone、Android 平板、iPad  
关联平台：Web、Windows、macOS（共享账号、账本数据、API 与同步规则）

## 1. 目标与设计原则

本计划的目标是把移动端从“桌面网页的移动容器”完善为适合手机单手操作、可长期使用的原生记账应用，同时保留 Neo Ledger 现有的深色界面、荧光绿色品牌色、卡片语言和跨平台数据能力。

钱迹等成熟记账产品只用于参考通用的信息架构和交互习惯，例如快速记账、月份切换、日期分组、分类宫格、原生设置列表和明确的空状态；不复制其品牌、视觉资产、文案、图标或专有功能设计。

实施过程中必须遵守以下原则：

1. 移动端、Web、Windows 和 macOS 使用同一个 AWS 服务、域名、账号、账本与 API，不能产生独立数据孤岛。
2. 移动端可以采用更适合触控的导航和页面结构，但金额口径、业务规则、权限和同步结果必须一致。
3. 所有新建、编辑、删除、转账和自动识别写入都必须支持幂等、离线队列、失败提示和恢复。
4. 原生页面完成前可以保留网页端高级管理入口，但不得把跳转网页标记为“原生功能已完成”。
5. Android 与 iOS 的系统能力不同，自动记账使用各自允许的实现，不伪造跨平台能力一致。
6. 每个阶段必须完成代码、自动化测试、构建验证和真机验收后才能勾选完成。

> 状态说明：本计划中的 `[x]` 表示代码、共享 API、自动化测试和当前可用构建已经完成；仍需要真机、Apple 开发环境、正式签名、生产对象存储或真实第三方账号的项目会在“外部验收门槛”中单独列出，不把无法在当前仓库内验证的事项误标为完成。

## 2. 当前基线

Native `1.4.0+21` 已完成第一阶段原生壳层：

- 已接入现有账本 API、会话恢复、离线写入队列和云端刷新。
- Web、Windows、macOS 继续使用统一网页端，不受移动布局影响。

截至本次继续开发，原生移动端已经覆盖：原生首页/账单/分析/我的、记账与转账、离线队列与失败草稿、账单搜索/组合筛选/日期范围/游标分页、详情编辑删除撤销、多选批量操作、预算/订阅/分期/储蓄目标、账户/数字资产、自动记账配置、应用锁、头像更新、数据导出恢复、首页模块和体验偏好跨设备同步、一级/二级分类和分类关系迁移、系统/深浅主题和高对比度、默认货币及金额格式、独立且逐次授权的截图 AI 识别接口、原生 MFA 管理。

当前还不能仅靠本仓库完成的主要事项是：账单附件的对象存储与跨端展示、iOS Share Extension/系统能力、真实 Android 厂商权限矩阵、iOS 工程和签名、正式发布与回滚，以及必须使用真机才能确认的性能、无障碍和隐私保护行为。

当前执行口径：截至 2026-09-25，仓库内无需外部账号、真机、签名或对象存储的移动端实现已完成并通过自动化质量门；清单中仍未勾选的项目均属于真实设备/发布账号/外部服务/正式回滚责任范围，或需要这些条件才能形成有效证据，不再用本地模拟结果冒充完成。

必须按下列顺序推进。后一阶段可以提前做技术调研，但不能绕过前一阶段的验收门槛直接宣称完成。

## 5. 阶段 1：完整记账体验

这是最高优先级。完成前不扩展装饰性首页模块。

### 5.1 金额与类型

- [x] 支出、收入、转账三种类型使用统一的顶部切换控件。
- [x] 数字键盘支持小数、退格、清空、加减连续计算和最大金额限制。
- [x] 输入数字时提供可关闭的轻触震动和金额过渡动画。
- [x] 防止 `0`、负数、超长小数和超出服务端范围的金额提交。
- [x] 保存按钮持续显示当前类型和金额，提交过程中禁止重复点击。

### 5.2 分类与账户

- [x] 显示最近使用分类、一级分类和二级分类；移动端选择器会显示父级名称并支持按父级搜索。
- [x] 分类支持图标、颜色、搜索和用户自定义排序。
- [x] 记住每种分类最近使用的账户，但不静默覆盖用户本次选择。
- [x] 账户选择显示余额、币种和账户类型。
- [x] 收入和支出分别使用自己的分类集合。

### 5.3 账单字段

- [x] 日期和具体时间，提供今天、昨天、前天快捷入口。
- [x] 商户/标题、备注、标签、参与人和情绪/刚需属性。
- [x] 报销状态、优惠金额和不计入收支/预算的标记。
- [ ] 账单图片支持拍照、相册、压缩、预览、删除和上传失败重试。
- [x] 多币种账单显示原币金额、汇率和本位币金额。
- [x] 连续记账模式：保存后清空金额，保留用户选择的账户和日期。

### 5.4 保存与离线

- [x] 保存后立即乐观显示在账单列表，并标记同步状态。
- [x] 离线保存进入本地队列，恢复网络后自动补发。
- [x] 同一账单重复点击、重启重试或网络超时不得造成重复写入。
- [x] 保存失败时保留输入内容，重新打开记账页可恢复本地草稿；同步失败的队列项保留并自动重试。

### 5.5 验收标准

- 单手可在 10 秒内完成一笔常用支出。
- 收入、支出、转账和多币种金额在移动端与 Web 端结果一致。
- 连续点击保存不会生成重复流水。
- 断网记账、杀进程、重新打开、恢复网络后数据能够正确同步。
- 软键盘弹出、横竖屏切换和系统大字体下保存按钮不被遮挡。
